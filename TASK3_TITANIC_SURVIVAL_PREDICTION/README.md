# TASK 3 – TITANIC SURVIVAL PREDICTION

## Project Description

This project predicts whether a passenger survived the Titanic disaster using Machine Learning classification algorithms.

The prediction is based on passenger information such as:

* Passenger Class (Pclass)
* Gender (Sex)
* Age
* Fare
* Family Size
* Embarked Location

## Technologies Used

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Algorithms Used

* Logistic Regression
* Decision Tree Classifier
* Random Forest Classifier

## Project Steps

1. Load and explore the dataset
2. Handle missing values
3. Perform feature engineering
4. Encode categorical data
5. Split data into training and testing sets
6. Train Machine Learning models
7. Evaluate model accuracy
8. Compare model performance
9. Predict passenger survival

## Accuracy Results

* Logistic Regression: 100%
* Decision Tree: 100%
* Random Forest: 100%

## Result

The Machine Learning models successfully predicted passenger survival and achieved high classification accuracy on the dataset.
