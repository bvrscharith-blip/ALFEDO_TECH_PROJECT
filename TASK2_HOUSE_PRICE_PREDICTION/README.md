# TASK 2 – HOUSE PRICE PREDICTION

## Project Description

This project is used to predict house prices using Machine Learning regression algorithms.

The prediction is done using house features such as:

* Bedrooms
* Bathrooms
* Square Feet
* Floors
* House Condition
* Year Built

## Technologies Used

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Algorithms Used

* Linear Regression
* Random Forest Regressor
* Gradient Boosting Regressor

## Project Steps

1. Import libraries
2. Load dataset
3. Perform data visualization
4. Preprocess data
5. Train regression models
6. Evaluate RMSE and MAE
7. Compare model performance
8. Predict house prices


## Result

The Machine Learning models successfully predicted house prices with good accuracy.
