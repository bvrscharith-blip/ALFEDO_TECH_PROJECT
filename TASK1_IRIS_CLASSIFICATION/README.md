# TASK 1 – IRIS CLASSIFICATION

## Project Description

This project is used to classify iris flowers into different species using Machine Learning algorithms.

The flower species are:

* Setosa
* Versicolor
* Virginica

The classification is done using:

* Sepal Length
* Sepal Width
* Petal Length
* Petal Width

## Technologies Used

* Python
* Jupyter Notebook
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-learn

## Algorithms Used

* KNN
* Logistic Regression
* Decision Tree

## Project Steps

1. Import libraries
2. Load dataset
3. Perform data visualization
4. Train Machine Learning models
5. Test model accuracy
6. Compare model performance
7. Predict flower species


## Result

The Machine Learning models successfully classified iris flowers with high accuracy.
